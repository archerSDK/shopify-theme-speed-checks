# Shopify Theme Speed Checks You Can Finish in an Afternoon

Practical checklist for Shopify storefronts that feel heavy. Work through these in one focused afternoon.

## Checks

1. **Measure first** — Run Lighthouse / Theme Inspector on home, a product page, and cart. Note LCP, TTFB, and long tasks.
2. **App embeds & sections** — Disable unused app embeds and theme sections; keep the checkout path lean.
3. **Images** — Use Shopify CDN size params; compress large media; lazy-load below the fold.
4. **Liquid weight** — Reduce loops that hit metafields or collections on every render.
5. **JavaScript** — Defer non-critical scripts; audit third-party tags that block interaction.
