Shopify Theme Speed Checks You Can Finish in an Afternoon

Theme weight and app scripts quietly tax every session. This is the afternoon pass we use before rewriting a storefront.

1. Measure first

  • Run Lighthouse and WebPageTest on a collection page and a product page.
  • Record JS payload and the largest contentful paint element.

2. Liquid and sections

  • Remove unused sections and metafield loops that run on every template.
  • Prefer native sections over nested apps that re-render the whole page.

3. Images

  • Use Shopify CDN responsive images with width parameters; avoid oversized masters.
  • Set explicit dimensions; lazy-load non-LCP media.

4. Apps and scripts

  • Disable apps that inject sitewide JS for a single feature.
  • Load reviews and upsells after first interaction when the theme allows.

5. Checkout-safe habits

  • Keep critical CSS small; avoid blocking font loads on mobile.
  • Retest after each change; ship only wins that hold on a mid-range phone.
